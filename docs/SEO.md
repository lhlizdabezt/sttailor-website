# Technical SEO controls

The build generates public routes with unique titles and descriptions, a production canonical URL, Open Graph metadata, and indexing directives. The XML sitemap includes editorial images and the fitting film. The robots file advertises the sitemap. Every public page links to `llms.txt`, which groups the canonical URLs with English and Vietnamese summaries. Each canonical URL serves both languages in the initial HTML with language attributes. Reserve `hreflang` for independently published language variants. The 404 document uses `noindex` without a homepage canonical. Sitemap `lastmod` dates reflect meaningful content changes.

Public pages, editorial media, responsive images, icons, stylesheets, scripts and the public build manifest are crawlable. `/image-manifest.json` publishes dimensions and responsive URLs for approved public images. Production verification checks delivery status, file types and indexing directives. Search engines decide which eligible resources to index. Error pages and retired account and admin endpoints return HTTP 404 with `noindex`. Private credentials and business identity scans stay outside the public website and GitHub source backup.

Approved full-resolution HEIC downloads have their own inventory in `src/public-photo-archives.js`. The build checks each approved file's SHA-256 before copying it, and its download URL sends `X-Robots-Tag: noindex`. Sanitize and review any new archive copy before adding its path and hash. The editorial versions remain discoverable in the image sitemap.

The generated JSON-LD describes the business, website, navigation, service catalog, and page breadcrumbs. The Client Care page also publishes an `ItemList` with English and Vietnamese names for each guide and policy it links to.

Run `npm run build && npm run check` before every push. Register new HTML templates in `source/wordpress` with a public route. The build checks for templates without a route before it replaces `dist`. The release checks compare the original photo inventory with the image manifest and the published files, then confirm each page's image sitemap entries cover its editorial photos. They also check canonical URLs, indexing directives, structured data and the IndexNow ownership key. `npm run verify:live` tests production headers, canonical URLs, robots, sitemap, IndexNow key delivery, redirects, 404 behavior, and public route responses.

The GitHub deployment workflow notifies Bing IndexNow after production verification. The key is intentionally public at the canonical root as required by the protocol; it is not an account credential. See [SEO operations](SEO-OPERATIONS.md) for the operational checklist.

For Gallery, Payment and Client Care, `derivedContentModified` in `scripts/build.mjs` records the approved transformed-copy dates. Advance only the affected entry when its copy changes. Source-page, Gallery-media and Client Care module history can advance their relevant dates automatically; editing the build machinery alone must not refresh them. The 2026-10-26 portability fix preserves the existing published dates.
